# 슬롭랩 개선 점검 (2026-11-09)

점검 방법: 실제 사이트 직접 확인(PC·휴대폰 크기), Supabase 보안·성능 점검, 코드 보안 검토, 코드 버그·사용성 검토.
현재 상황: 회원은 운영자 1명뿐이고, 외부 사람의 투표·댓글은 0개예요.

## 이미 고친 것

- **이미지 링크 보안 구멍** (2026-11-09 수정·배포): 사이트를 거치지 않고 API를 직접 부르면 `javascript:` 링크를 "이미지"로 저장할 수 있었고, 누가 그 이미지를 누르면 공격 코드가 실행돼 로그인 정보를 빼앗길 수 있었어요. 이제 `https://` 주소나 사이트 안 경로만 보여 줘요 (`src/text.js` safeImg). 저장된 데이터는 모두 깨끗했어요.

## 2단계: 검색·공유로 사람이 찾아오게

- 글마다 공유용 페이지가 곧바로 홈 주소(#/p/...)로 넘겨서 구글이 글을 따로 색인하지 못할 수 있음 → 글마다 진짜 주소(/slop-lab/p/글번호/)로 열리게.
- 공유 미리보기 이미지가 모든 글에서 같음 → 글 제목이 들어간 미리보기 이미지를 글마다 자동 생성.
- 공유 페이지가 전부 한국어(lang="ko"), 영어(og:locale en_US)로 고정 → 글 언어에 맞게.
- 구글 서치 콘솔 사이트맵이 "가져올 수 없음" 상태 → 파일은 정상이라 다시 제출하면 됨(승인 필요).
- (선택) 자기 도메인(예: sloplab.app): 연 1~3만 원, 기억하기 쉽고 신뢰도·검색에 유리.

## 3단계: 사용 중 버그 (코드 검토)

- 판정 화면에서 ▲를 두 번 빠르게 누르면 투표가 취소되고, 이유를 두 번 등록할 수 있음 (`src/views/judge.js:68`).
- 빠르게 다른 메뉴로 이동하면 이전 화면이 늦게 도착해 덮어씀 (판정→커뮤니티 등).
- 로그인 후 "뒤로"를 누르면 로그인 화면↔홈을 무한 반복. 로그인 후 원래 보던 글로 안 돌아감.
- 프로필 메뉴가 한 번 닫히고 나면 바깥을 눌러도 안 닫힘 (`src/main.js:77`).
- 프로필 페이지의 앱 미리보기가 계속 "준비 중"으로 멈춤 (`src/views/pages.js:86`).
- "더 보기"가 실패하면 목록 전체가 오류로 바뀜, 더 보기 할 때 모든 미리보기 앱이 다시 시작됨.
- 삭제 확인을 빠른 두 번 클릭으로 건너뛸 수 있음, 댓글 삭제는 확인 없음.
- 주소에 `%`가 있으면 화면이 멈춤, 없는 글은 "새로고침" 안내 대신 "없는 글" 안내가 맞음.
- 알림을 누르면 해당 댓글이 아니라 글 맨 위로 감. 글 수정 중 나가도 경고 없음.
- 접근성: 대화상자가 키보드로 빠져나감, 이름 없는 버튼(아바타·이미지 링크), 작은 터치 영역(19~25px), 라이트 모드의 청록·주황 글자 대비 부족, 상단 메뉴가 넘치면 끝 메뉴(저장함·운영)에 못 감.
- 불필요한 요청: 정렬·검색 때마다 통계·커뮤니티 목록 다시 받음, 운영 화면이 글을 하나씩 따로 받음, 글 열 때 코드 전체를 두 번 받음.

## 4단계: 신뢰·운영 (특히 해외 사용자)

- 이용약관·개인정보 처리방침·콘텐츠 정책 페이지가 없음 (이메일을 받는 사이트라 필요).
- 계정 삭제 기능이 없음 (해외 사용자 권리).
- 방문자 수를 알 수 없음 → 외부 서비스 없이 Supabase로 간단히 집계 + 글마다 조회수 표시(빈 사이트처럼 안 보이게).
- 차단된 사용자도 신고·팔로우 가능, 차단 사유가 공개됨, 자기 글에 투표 가능(API 직접 호출 시).

## 5단계: 성장 아이디어 (나중에)

- 앱 퍼가기 코드(블로그 등에 붙이기) + "Made with Slop Lab" 표시.
- 이번 주 보석 정리 글·뉴스레터, 댓글 알림 메일(메일 서비스 필요).
- 만든 사람 점수·배지, 주간 순위.
- 이미지 설명(alt) 입력칸.

## 6단계: 데이터베이스 (사람이 늘 때 대비)

- 보안 규칙 25개가 행마다 로그인 정보를 다시 계산 → `(select auth.uid())` 형태로 바꾸기.
- 인덱스 없는 외래 키 14개 → 인덱스 추가.
- 지금 데이터 양에서는 체감 차이 없음. 응답 속도는 0.1~0.5초(첫 연결만 약 1초)로 양호.

## 괜찮았던 것

- 첫 화면 표시 0.7초, JS 68KB(압축).
- 사용자 앱 격리(iframe sandbox), 글 서식 변환, 공유 페이지 생성, 관리자 권한 처리: 문제 없음.
- 판정 화면은 휴대폰에서 버튼이 아래에 고정돼 쓰기 편함.
- 사이트맵·RSS 파일 형식 정상, Supabase 서버는 도쿄(한국에서 빠름).
- 비밀번호 유출 검사 기능은 Supabase 유료 요금제에서만 켤 수 있어 제외.
